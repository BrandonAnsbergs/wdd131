Purpose

The purpose of the Fitness Tracker website is to empower users to take control of their fitness journey. It provides tools to easily log workouts, track progress over time, and access helpful resources like exercise recommendations, nutritional guidance, and practical fitness tips, motivating users to stay consistent and achieve their health goals.

Audience

This site targets individuals actively pursuing fitness goals, ranging from beginners seeking guidance to experienced enthusiasts wanting a simple way to monitor their activity. The audience includes those interested in weightlifting, cardio, general fitness, and improving their diet. They are likely looking for a straightforward, user-friendly platform accessible on desktop or mobile devices to keep track of their efforts and find motivation and information.

  • **Needs:** Easy workout logging, progress visualization, reliable fitness/nutrition info.
  • **Motivations:** Improve health, build strength, lose weight, stay consistent, learn new exercises/diets.
  • **Technical Skill:** Varies from basic web users to moderately tech-savvy individuals.

Description of Dynamic Elements (JavaScript)

JavaScript will be used extensively on the 'Track' page and potentially other areas to enhance user experience:

  • Workout Logging (Track Page):
    • **DOM Interaction:** Select the workout input form, listen for the 'submit' event. Select the workout list area (`
        `).
      • **Data Handling:** Create JavaScript `Object`s for each workout entry (containing date, exercise, duration, description). Store these objects in an `Array`.
      • **Local Storage:** Use `localStorage` to save the workout array, allowing data to persist between browser sessions. Use `JSON.stringify` to save and `JSON.parse` to retrieve.
      • **Dynamic Content Update:** When a workout is added or deleted, dynamically update the HTML of the workout list using DOM manipulation (e.g., setting `innerHTML` or using `createElement`, `appendChild`). Array methods like `map()` or `forEach()` will be used to generate the list items.
      • **Conditional Branching:** Check if there are existing workouts in `localStorage` on page load. Display a "No workouts logged yet" message if the array is empty.
    • Workout Deletion (Track Page):
      • **DOM Interaction:** Add event listeners (likely directly in the HTML via `onclick` or dynamically added) to 'Delete' buttons associated with each workout entry.
      • **Data Handling:** Use the workout's index in the array to identify which entry to remove. Use the `splice()` array method to remove the item. Update `localStorage`.
      • **Dynamic Content Update:** Re-render the workout list after deletion.
    • Exercise Recommendations (Exercises Page - Potential):
      • **DOM Interaction:** Select elements to display exercises.
      • **Data Handling:** Could potentially filter or sort exercises based on user input (e.g., muscle group) using array methods like `filter()`. Exercise data could be stored in an array of objects.
      • **Dynamic Content Update:** Display the filtered/sorted exercises dynamically.
    • Progress Visualization (Optional Enhancement - e.g., on Home or Track Page):**
      • As shown in the example code, a library like Chart.js could be used.
      • **DOM Interaction:** Select the `canvas` element.
      • **Data Handling:** Process the `workouts` array (using `map()` or `reduce()`) to extract data suitable for charting (e.g., duration over time).
      • **Dynamic Content Update:** Generate or update the chart based on the workout data.
    • General Requirements:**
      • **Organization:** Code will be organized into multiple functions (e.g., `addWorkout`, `deleteWorkout`, `renderWorkoutList`, `loadWorkouts`).
      • **ES Modules:** JavaScript code can be structured using ES Modules (`import`/`export`) for better organization, especially if scripts become larger.

Content

Outline of content for each page:

Home Page

  • **Goal:** Introduce the website, highlight key features, and provide calls to action.
  • **Text:**
    • Hero Section: Welcome message, brief description, "Get Started" button.
    • Features Section: Headings and short descriptions for logging, progress visualization, and learning resources.
    • Quick Log Section (Optional on Home): Basic form for quick workout entry (Date, Type, Duration).
    • Recent Workouts (Optional on Home): Display a few recent entries.
    • Progress Overview (Optional on Home): Simple chart or summary.
    • Testimonials: User quotes about the site's benefits.
    • Call-to-Action: Encourage users to log their first workout.
  • **Images:** Hero background image (fitness-related), potentially icons for features.

Track Page

  • **Goal:** Allow users to input detailed workout logs and view/manage their past entries.
  • **Text:**
    • Form Heading: "Log Your Workout" or similar.
    • Form Fields/Labels: Date, Exercise/Workout Type, Duration (minutes), Description/Notes.
    • Submit Button: "Add Workout" / "Log Workout".
    • Logged Workouts Heading: "Your Workout History" / "Logged Workouts".
    • Workout List Area: Placeholder text if no workouts exist ("No workouts logged yet.").
    • Workout Entry Display: Show Date, Type, Duration, Description for each logged item.
    • Delete Button: Button next to each entry to remove it.
  • **Images:** Minimal images needed, perhaps icons for form fields or workout types if desired. Focus is on the form and data display.

Tips Page

  • **Goal:** Provide actionable advice on fitness, exercise technique, motivation, and recovery.
  • **Text:**
    • Page Title: "Fitness Tips & Advice".
    • Sections/Articles: Organize tips by category (e.g., Workout Tips, Nutrition Tips, Motivation Hacks, Recovery Strategies).
    • Content: Short, digestible tips in paragraphs or bullet points. Focus on practical advice.
  • **Images:** Images related to specific tips (e.g., demonstrating a stretch, healthy food, workout gear).

Exercises Page

  • **Goal:** Offer a reference library of exercises, potentially categorized by muscle group or equipment.
  • **Text:**
    • Page Title: "Exercise Library" / "Workout Ideas".
    • Categories: Headings for different exercise types (e.g., Chest, Back, Legs, Cardio, Bodyweight).
    • Exercise Descriptions: Name of the exercise, instructions on how to perform it, target muscles.
    • Recommended Splits/Routines: Example workout routines (e.g., Push-Pull-Legs, Full Body).
  • **Images/Diagrams:** Illustrations or photos demonstrating correct exercise form.

Nutrition Page

  • **Goal:** Provide guidance on healthy eating, meal planning, and nutritional information relevant to fitness goals.
  • **Text:**
    • Page Title: "Nutrition Guide".
    • Sections: Topics like Macronutrients, Micronutrients, Hydration, Meal Timing, Healthy Recipes, Diet Examples (e.g., balanced, high-protein).
    • Content: Informative text, possibly recipe instructions, sample meal plans.
  • **Images:** Photos of healthy foods, prepared meals, infographics about nutrition.
